devbox-rclone privacy policy

Last updated: 17 November 2026.

devbox-rclone is a personal tool. Its only user is its owner, Shantanu.

What data it accesses

With the owner's permission, it reads and writes files in the owner's own Google Drive using the Google Drive API.

How the data is used

Files are copied only to the owner's own laptop or the owner's personal cloud virtual machine, so the owner and AI coding assistants acting on the owner's instructions can work on them. Data is not sold, used for advertising, or made public. When the owner asks an AI assistant to work on selected files, the relevant content may be processed by that assistant's provider under the owner's account and its data settings.

Storage

Copied files and the access token stay on the owner's own laptop and personal virtual machine. Selected content may be processed by AI assistant providers as described above. Nothing is stored on this website.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Google API use complies with the Google API Services User Data Policy, including the Limited Use requirements.
